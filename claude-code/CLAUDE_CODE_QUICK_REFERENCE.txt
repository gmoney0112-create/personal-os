┌─ TROUBLESHOOTING (When Things Break) ──────────────────────────────────────┐
│                                                                              │
│  Problem: GHL webhook not firing                                             │
│  → Check webhook URL is correct in GHL UI                                   │
│  → Verify Location ID in your code                                           │
│  → Test webhook in GHL UI (Send Test button)                                │
│                                                                              │
│  Problem: Netlify deploy hangs                                               │
│  → You have a heavy dependency (ML model, large lib)                        │
│  → Solution: Use lightweight libs, offload to Supabase edge functions       │
│                                                                              │
│  Problem: Payment webhook missed                                             │
│  → Race condition. Webhook arrived before order was ready.                  │
│  → Solution: Add 500ms delay on webhook handler                             │
│                                                                              │
│  Problem: SMS not sending                                                    │
│  → Twilio/platform account deactivated mid-month                            │
│  → Solution: Pre-fund account, set billing alerts                           │
│                                                                              │
│  Problem: Agent "forgets" context between sessions                           │
│  → Session timeout. State not persisted.                                    │
│  → Solution: Store state in Supabase, load on resume                        │
